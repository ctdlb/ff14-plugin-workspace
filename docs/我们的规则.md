# 规则索引（只指路，不抄条文）

> 本文件**只告诉你「哪条规则在哪」，不写规则内容**——条文只有一份原文，避免两份写法漂移后互相矛盾。
> 想改规则：按 `E:\DeepSeek Harness\AGENTS.md` 的「经验同步」一节做（那节写了改法）。
> 最后更新：2026-10-25

## 一、生效范围

| 层 | 文件 | 谁读它 |
|---|---|---|
| 用户级 | `%USERPROFILE%\.dsh\AGENTS.md` | DSH 每次启动都读，**所有工作区、所有新对话** |
| 工作区级 | 工作区根目录的 `AGENTS.md` | **只在那一层目录开对话时**加载（红线、插件通用经验都在这里） |
| 本文件 | `E:\DeepSeek Harness\docs\我们的规则.md` | 不生效，只是索引 |

用户级规则的正本备份在 `ctdlb/dsh-plugins` 仓库根目录的 `AGENTS.md`；本工作区怎么处理这份副本见 `AGENTS.md` → 环境事实 · 用户级规则文件。
